# Checklist de seguimiento — SOKACH

## Cómo utilizar esta lista

- Marcar una tarea únicamente cuando esté realizada y comprobada.
- No interpretar una propuesta como aprobación del cliente.
- Mantener las tareas pendientes aunque se haya completado otra parte de la etapa.
- Actualizar el registro al cerrar hitos, no por cada cambio pequeño.
- Crear un respaldo antes de cambios destructivos o migraciones.
